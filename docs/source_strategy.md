# Source strategy

The active catalog contains 23 sources used by study-planning records: 11 learning-evidence sources and 12 subject-framework sources. Records preserve source IDs, reuse notes, access dates, limitations, evidence roles, and review state.

Learning evidence supports cautious study-method summaries. Subject frameworks support curriculum-neutral subject and topic descriptions but cannot be treated as proof of learning effectiveness. Session durations and timer breaks are explicit design proposals, not universal findings.

Hardware and sensors are outside the AI knowledge scope, so hardware-only source mappings are not present in the active catalog.
